# 测墙：这个 IP 在国内还能用吗

一个只读的检测脚本。**不建机器、不装东西、不改任何配置**，3~15 秒给结论。

回答一个问题：**你这个 IP，从国内还能不能连？** 能就继续用，不能就换 IP —— 别的都不用查。

```
.\Test-Blocked.ps1 45.76.1.1
```

或者双击 `测墙.bat`。不带参数时，它会自己从上一层的 `nodes.txt` 里翻出最近一台的 IP。

## 输出长什么样

```
  [OK] 检测视角：当前 IP：111.15.8.239 来自于：中国 山东 青岛 移动  —— 在国内，结果可作数

==> 检测 45.76.1.1
  [OK] ICMP        4/4 回包   平均 132 ms
  [OK] TCP 443      通        140 ms
  [OK] TLS 握手    HTTP 200   www.microsoft.com:443 直连成功

  ==> 结论：没被墙，链路可用
```

被墙的时候：

```
  [!!] ICMP        4 次全无回包（有的机器禁 ping，先看下面的 TCP）
  [XX] TCP 22       超时
  [XX] TCP 443      超时
  [XX] TLS 握手    失败（000 / 超时，一直没有响应）

  ==> 结论：三层全无响应（ICMP 也没回包） —— 被墙，或者机器根本没开机
      · Vultr 后台看一眼实例是不是 running
      · 实例在跑、IP 也是这个，那就是 IP 被墙了，Destroy 重建换一个
```

## 为什么不是"ping 一下"

ping 通不代表能用，ping 不通也不代表被墙。所以打三层，**任何一层活着就不算被墙**：

| 层 | 测什么 | 不通说明 |
|---|---|---|
| 1. ICMP | ping 4 次 | 什么都不说明。很多机器默认禁 ping |
| 2. TCP | 裸连 22 / 80 / 443 | 一个都不通，才像 IP 级封锁 |
| 3. TLS 真握手 | 用 SNI 直连服务器 IP，取 `https://<SNI>/` | 拿到 2xx/3xx/4xx 才算链路真的活着 |

第 3 层是关键。`TCP 443 能连上` 和 `能正常跑 Reality` 是两回事：Reality 会把"没有正确密钥"的 TLS 连接原样中转给真站（默认 `www.microsoft.com`），所以能拿到 HTTP 状态码，就说明这条路从头到尾是通的，而不只是三次握手过了。

TCP 那层的端口是**并发**探的，三个端口最坏也只要一个超时的时间。

## 前置条件：必须在国内跑

墙只挡"国内 → 境外"这条路。从境外、或者挂着代理跑，测出来"通"什么也证明不了。

脚本开头会先查本机出口在哪（走 `myip.ipip.net`，**强制直连、绕开系统代理** —— 否则 v2rayN 一开系统代理，报的就是代理的出口）。查出来不在国内，会直接告诉你结果不作数。

不想让它访问这个接口，加 `-NoVantage`。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `-Ip` | 读 `nodes.txt` | 要测的 IP，可多个逗号分隔 |
| `-Ports` | `22,80,443` | 探哪些 TCP 端口 |
| `-TlsPort` | `443` | 做真握手用哪个端口。换过 Xray 端口就一起改 |
| `-Sni` | `www.microsoft.com` | 握手用的伪装域名，必须和服务端一致 |
| `-TimeoutMs` | `4000` | 单个 TCP 连接的等待毫秒数 |
| `-SkipPing` | - | 跳过 ICMP，省 4 秒（机器禁 ping 时直接用它） |
| `-NoVantage` | - | 不查本机出口位置 |

常用变体：

```powershell
.\Test-Blocked.ps1                              # 测 nodes.txt 里最近一台
.\Test-Blocked.ps1 45.76.1.1,45.76.1.2          # 一次测多个，末尾有汇总
.\Test-Blocked.ps1 45.76.1.1 -SkipPing -NoVantage    # 最快的一档
.\Test-Blocked.ps1 45.76.1.1 -Ports 22,8443 -TlsPort 8443
```

## 退出码

给批处理 / 别处调用看的：

| 码 | 含义 | 你该做什么 |
|---|---|---|
| 0 | 通了 | 接着用 |
| 1 | 被墙 / 完全不通 | 换 IP：Vultr 后台 Destroy 重建，或 `.\deploy.ps1 -New` |
| 2 | IP 没被整封，但握手失败 | **别急着换机器**。先 `ssh` 上去 `systemctl status xray`，再看端口和 SNI |

## 三种"通但不正常"，别误判成被墙

| 现象 | 真正的原因 |
|---|---|
| ICMP 全丢，TCP 通 | 机器开了禁 ping，正常。看 TCP 结果就行 |
| TCP 443 通，握手 `000` + `TLS 握手被打断` | 端口被单独阻断 / Xray 没在跑 / SNI 不对。先查服务，再试 `-TlsPort 8443` |
| 握手失败，报 `curl 退出码 6` | 本机 DNS 的问题，和墙无关 |

另外：**本机时间误差超过 60 秒，Reality 也会握手失败**，而且看起来和被墙一模一样。先确认 Windows 开了"自动设置时间"。
